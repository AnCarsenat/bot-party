# Contributing to Bot Party

Thanks for wanting to help! Bug reports, ideas, code, levels, items and art are
all welcome.

## How

1. Open an issue first for anything big, so we can agree on it.
2. Fork the repository, make your change on a branch, and open a pull request.
3. Test it in Godot 4.7 (the game should run without errors in the output).
   Keep the style of the code around it: small functions, comments that say
   *why*, plain words in the game's texts.

You don't need to contribute here to make content: mods (items, maps, game
modes, textures) can be made and shared on their own. See
[MODDING.md](MODDING.md). Mods are yours, under your own license.
